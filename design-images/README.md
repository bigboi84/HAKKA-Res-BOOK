# Design images

Drop compressed photos here so they can go into the website design (and later into WordPress).

## How to prepare each photo

1. Open it in **Squoosh** (squoosh.app) or batch them in **XnConvert**.
2. Resize to the size listed below, save as **WebP**, quality **75–80**.
3. Aim for **under 400 KB** each (heroes) and **under 250 KB** (everything else).
4. Rename it to the exact file name below (lower case, hyphens).
5. Upload on GitHub: open this folder → **Add file → Upload files** → commit to branch `claude/pensive-euler-eq60dw`.

Missing a shot? Skip it — the design keeps a placeholder there. Higgsfield images can go in the same way (download from Higgsfield, compress, rename).
